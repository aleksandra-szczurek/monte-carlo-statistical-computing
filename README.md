# Monte Carlo Simulation and Statistical Computing in R

**Group project** – Statistical Computing Methods, University of Perugia (Oct–Dec 2025)

A series of analyses in R implementing core simulation and optimisation algorithms **from scratch**.

## Contents

| File | Topics |
|---|---|
| `01_rejection_sampling_mc_integration.pdf` | Rejection sampling with different proposals (choosing the optimal one), Monte Carlo estimation of 8 single and double integrals with convergence monitoring |
| `02_importance_sampling.pdf` | Classical Monte Carlo vs importance sampling: a well-chosen proposal makes the estimate **more than 7 times more efficient** |
| `03_numerical_optimisation_mle.pdf` | Newton-Raphson and golden-section search, convergence from different starting points, maximum likelihood estimation for a Cauchy distribution |
| `04_bootstrap.pdf` | Inverse-transform simulation, maximum likelihood estimation of an exponential rate and bootstrap standard errors |

## Skills

Monte Carlo simulation · Rejection and importance sampling · Numerical optimisation · Maximum likelihood · Bootstrap · R
